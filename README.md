# MindTurtle 🐢

Welcome to MindTurtle - An intelligent educational platform that transforms learning through AI-powered interactions and personalized education.

## Overview

MindTurtle is a comprehensive learning management system that combines traditional education methods with cutting-edge AI technology. Our platform provides an interactive learning environment for both students and teachers, featuring AI-powered assistance through Gemini integration.

## Features

- 📚 **Course Management**
  - Create and manage interactive courses
  - Track student progress in real-time
  - Detailed course analytics and insights

- ✍️ **Assignment System**
  - Create and grade assignments
  - Automated progress tracking
  - Real-time feedback system

- 🤖 **AI-Powered Chatbot**
  - Intelligent tutoring powered by Gemini AI
  - 24/7 learning assistance
  - Personalized learning support

- 💻 **Code Playground**
  - Interactive coding environment
  - Real-time code execution
  - Multi-language support

- 📊 **Smart Dashboard**
  - Personalized student dashboards
  - Teacher analytics center
  - Performance metrics and insights

- 📋 **Todo Management**
  - Smart task organization
  - Deadline tracking
  - Priority management

## Tech Stack

- **Frontend:** React with TypeScript
- **Build Tool:** Vite + esbuild
- **State Management:** React Context API
- **AI Integration:** Google Gemini
- **Styling:** Modern CSS-in-JS

## Getting Started

### Prerequisites
- Node.js (Latest LTS version recommended)
- A Gemini API key

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/mindturtle.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   - Create a `.env.local` file in the root directory
   - Add your Gemini API key:
     ```
     GEMINI_API_KEY=your_api_key_here
     ```

4. Start the development server:
   ```bash
   npm run dev
   ```
